# GMPilot 项目进展总结 - 2026-06-18

## 一、项目概述

GMPilot 是制药行业 GMP 偏差报告生成工具，采用 Electron 桌面应用架构。

### 技术栈

| 层次 | 技术 | 版本 |
|------|------|------|
| 桌面框架 | Electron | 28.3.3 |
| 前端 | React + TypeScript + Tailwind CSS | 18.3.1 |
| 状态机 | XState | 5.19.0 |
| LLM | Vercel AI SDK | 4.3.19 |
| RAG | sqlite-vec + better-sqlite3 | 0.1.9 / 11.10.0 |
| 构建 | Vite + electron-vite | 5.4.21 |

### 核心功能

- **智能工作流**: 7 步 XState 状态机（输入→分析→因素→法规→生成→审核→完成）
- **多 LLM Provider**: 支持 9 个提供商（DeepSeek、通义千问、智谱、OpenAI、Anthropic、SiliconFlow、OpenRouter、Mimo、Ollama）
- **RAG 知识库**: 内置中国 GMP 14 章 + ICH Q9/Q10，支持向量检索
- **模版系统**: 6 个独立模版模块，支持单独生成和合并
- **多格式支持**: txt、pdf、docx、xlsx、图片
- **PDF 导出**: react-pdf 生成专业报告

### 6.3 性能问题

- **本地 Embedding**: 已优化为批处理
- **暴力向量搜索**: 已添加 LRU 缓存

## 七、配置说明

### 7.1 环境变量

```bash
# LLM 配置（统一模式）
LLM_API_KEY=your-api-key
LLM_BASE_URL=https://api.siliconflow.cn/v1
LLM_MODEL=deepseek-ai/DeepSeek-V3.2

# Embedding 配置
EMBEDDING_PROVIDER=openai
OPENAI_API_KEY=your-api-key
OPENAI_BASE_URL=https://api.siliconflow.cn/v1
EMBEDDING_MODEL=BAAI/bge-large-zh-v1.5

APP_DATA_DIR=./data
```
