# 模版管理 UI 实施计划

## 需求确认

1. **分屏预览**：左侧编辑，右侧实时预览
2. **双模式编辑**：支持 Markdown 编辑和表单编辑
3. **全部可编辑**：内置模版也可以直接编辑

## 实施步骤

### 步骤 1: 创建 TemplateManager 组件

**文件**: `src/components/settings/TemplateManager.tsx`

**功能**:
- 显示模版列表（标题、字段数、最后修改时间）
- 点击模版进入编辑模式
- 支持 Markdown 编辑和表单编辑切换
- 实时预览模版渲染效果
- 保存和重置功能

**UI 结构**:
```
┌─────────────────────────────────────────────────────────┐
│ 模版列表                                                  │
│ ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐          │

│ └─────────┘ └─────────┘ └─────────┘ └─────────┘          │
├─────────────────────────────────────────────────────────┤
│ 编辑器                                                  │
│ ┌─────────────────────────┬─────────────────────────┐   │
│ │                         │                         │   │
│ │  Markdown 编辑器        │  实时预览                │   │

│ │                         │                         │   │
│ │                         │                         │   │

│                                                         │

```

## 技术细节

### Markdown 编辑器

使用 `<textarea>` 实现简单 Markdown 编辑，支持：
- 语法高亮（可选）
- 行号显示
- 快捷键支持

### 表单编辑器

根据模版字段自动生成表单：
- 文本字段 → `<input>`
- 长文本 → `<textarea>`
- 布尔值 → `<checkbox>`
- 数组 → 动态列表

### 实时预览

使用模版渲染函数，将编辑内容转换为预览 HTML：
- 解析 Markdown 语法
- 渲染变量占位符
- 显示格式化后的内容

## 依赖

- 无额外依赖
- 使用现有 UI 组件（Button, Card, Input 等）
