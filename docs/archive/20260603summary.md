## 一、项目概述

**GMPilot** 是制药行业 GMP 偏差报告生成工具，基于 Electron 桌面应用，TypeScript 全栈技术栈。

### 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 桌面壳 | Electron 28 | 跨平台桌面应用 |
| 前端 | React 18 + TypeScript | UI 框架 |
| UI 库 | Ant Design 5 | 企业级组件 |
| 工作流 | XState v5 | 状态机引擎 |
| LLM | Vercel AI SDK | 40+ Provider 支持 |
| RAG | sqlite-vec + better-sqlite3 | 向量检索 |
| PDF | react-pdf | 报告生成 |

## 七、技术决策记录

### 1. 为什么选择 XState？

- 29.6K stars，社区成熟
- 确定性状态机，易于调试
- 可视化流程（Stately Editor）
- 与 Vercel AI SDK 集成良好

### 2. 为什么选择 sqlite-vec？

- 7.7K stars，活跃维护
- WASM 构建，无原生模块问题
- 与 better-sqlite3 统一存储层
- 支持余弦相似度检索

### 3. 为什么选择 react-pdf？

- 16.6K stars，React 组件式开发
- 支持中文字体嵌入
- CSS-like 样式模型
- 与 React 生态一致

### 4. 为什么选择本地 Embedding？

- 制药行业数据敏感
- 离线可用
- BAAI/bge-large-zh-v1.5 中文优化
- 1024 维向量，精度高

## 八、已知问题

1. **sqlite-vec 集成**
   - WASM 加载可能在 Electron 中失败
   - 已设计回退方案（内存检索）

2. **中文字体**
   - 思源宋体文件较大（~20MB）
   - 首次加载可能较慢

3. **流式生成**
   - XState 不直接支持流式状态
   - 需要通过 IPC 传递 chunk
