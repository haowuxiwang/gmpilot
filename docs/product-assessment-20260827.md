## 二、GMPilot 当前定位

**核心价值**：AI 驱动的偏差报告生成 + RAG 知识库 + 多工厂模板适配

**差异化优势**：
- LLM 自动生成调查报告（竞品无或刚起步）
- 本地 RAG 检索法规文档
- 多工厂模板自动解构（创新功能）
- 桌面应用，离线可用

**当前局限**：
- 单一功能（报告生成），非完整 QMS
- 缺少 QMS 核心模块（文档控制、培训、审核、变更）
- 缺少合规基础（电子签名、完整审计追踪）
- 无多用户/角色管理
- 无集成能力

## 三、距离分发的缺失项清单

### 3.1 合规基础（必须）

| 缺失项 | 说明 | 优先级 |
|---|---|---|
| **电子签名** | 21 CFR Part 11 要求对报告进行电子签名（起草人/审核人/批准人） | P0 |
| **完整审计追踪** | 不可篡改的操作日志，记录谁在何时做了什么修改 | P0 |
| **用户管理** | 多用户支持 + 角色权限（操作员/QA/管理员） | P0 |
| **数据完整性** | ALCOA+ 原则（可归因、清晰、同步、准确、完整、一致、持久、可用） | P0 |
| **代码签名证书** | Windows SmartScreen 警告，企业分发必须 | P0 |

### 3.2 功能模块（按需）

| 缺失项 | 说明 | 优先级 |
|---|---|---|
| **CAPA 追踪** | 不只是生成 CAPA 内容，还要追踪执行状态、有效性验证 | P1 |
| **文档控制** | 报告版本管理、审批流程、分发控制 | P1 |
| **变更控制** | 对已批准报告的变更申请、评估、批准流程 | P1 |
| **审核管理** | 内部/外部审核的计划、发现、整改追踪 | P2 |
| **培训管理** | 人员资质与 SOP 培训记录关联 | P2 |
| **看板/仪表板** | 偏差趋势、CAPA 状态、风险概览 | P2 |

### 3.3 技术基础（必须）

| 缺失项 | 说明 | 优先级 |
|---|---|---|
| **NSIS 安装包** | 当前只有 dir/portable，需要安装程序 | P0 |
| **自动更新** | electron-updater 已安装但未配置更新源 | P1 |
| **崩溃报告** | Sentry 或类似服务，收集生产环境问题 | P1 |
| **性能监控** | 关键操作耗时监控（LLM 调用、索引构建） | P2 |
| **备份/恢复** | 数据库备份与恢复机制 | P2 |

### 3.4 用户体验（建议）

| 缺失项 | 说明 | 优先级 |
|---|---|---|
| **首次启动引导** | API key 配置引导、模板选择引导 | P1 |
| **帮助文档** | 用户手册、操作指南、FAQ | P1 |
| **快捷键** | 常用操作的键盘快捷键 | P2 |
| **深色模式** | 系统级深色主题支持 | P2 |
| **国际化** | 中英文界面切换 | P2 |

### 3.5 部署运维（必须）

| 缺失项 | 说明 | 优先级 |
|---|---|---|
| **安装包签名** | 代码签名证书（EV 证书更佳） | P0 |
| **更新服务器** | electron-updater 的更新源（GitHub Releases / 自建） | P1 |
| **日志收集** | 生产环境日志远程收集（脱敏后） | P1 |
| **数据迁移** | 版本升级时的数据库迁移脚本 | P2 |

## 五、与竞品的竞争策略建议

**不建议**：直接与 MasterControl/TrackWise/Veeva 竞争完整 QMS 市场

**建议定位**：
1. **AI 偏差报告助手** — 作为现有 QMS 的补充工具（集成而非替代）
2. **中小工厂轻量 QMS** — 50 人以下工厂，无需完整 QMS，只需报告生成
3. **多工厂模板适配** — 集团企业下属工厂模板不统一，需要自动解构

**核心护城河**：
- LLM 生成质量（提示词工程 + RAG）
- 多工厂模板自动适配（创新功能）
- 桌面应用离线可用（区别于云 QMS）
