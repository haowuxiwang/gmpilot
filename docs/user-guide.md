# GMPilot 用户指南

## 快速开始

### 1. 配置 LLM Provider

首次使用需要配置 LLM Provider：

1. 打开应用，进入"设置"页面
2. 在"LLM 配置"区域选择 Provider（推荐 Mimo 或 SiliconFlow）
3. 填入 API Key
4. 点击"测试连接"验证配置
5. 点击"保存设置"

### 2. 生成偏差报告

1. 进入"智能助手"页面
2. 在输入框中描述偏差情况，例如：
   ```
   2026年6月15日，片剂车间生产阿莫西林片(批号B2026001)时，
   片重差异检测结果为±8.5%，超出标准±5%。
   检查发现压片机冲头磨损严重未及时更换。
   ```
3. 可以上传相关文件（PDF、Word、Excel、图片）
4. 点击发送，等待报告生成
5. 在右侧文档面板查看报告详情
6. 点击"导出 PDF"保存报告

### 3. 管理知识库

1. 进入"知识库"页面
2. 点击"上传文档"添加法规文件
3. 支持格式：txt、pdf、docx、xlsx
4. 上传后系统会自动分块和向量化
5. 使用搜索功能查找相关法规

### 4. 管理模版

1. 进入"设置"页面
2. 在"模版管理"区域查看所有模版
3. 点击模版进入编辑模式
4. 支持 Markdown 编辑和表单编辑
5. 右侧实时预览模版效果
6. 编辑完成后点击"保存模版"

## 功能详解

### 多格式文件支持

| 格式 | 说明 | 用途 |
|------|------|------|
| .txt | 纯文本文件 | 线索描述、法规文件 |
| .md | Markdown 文件 | 文档、报告 |
| .csv | 逗号分隔值 | 数据表格 |
| .pdf | PDF 文档 | 法规文件、报告模板 |
| .docx | Word 文档 | 法规文件、报告模板 |
| .xlsx | Excel 文件 | 数据表格、记录 |
| 图片 | JPG/PNG | 现场照片、截图 |

### LLM Provider

支持 9 个 Provider：

| Provider | 说明 | 推荐场景 |
|----------|------|----------|
| Mimo | 小米 AI | 国内用户推荐 |
| SiliconFlow | 硅基流动 | 国内用户推荐 |
| DeepSeek | 深度求索 | 国内用户推荐 |
| 通义千问 | 阿里云 | 国内用户推荐 |
| 智谱 | 清华系 | 国内用户推荐 |
| OpenAI | GPT-4o | 海外用户 |
| Anthropic | Claude | 海外用户 |
| OpenRouter | 聚合平台 | 多模型切换 |
| Ollama | 本地模型 | 离线使用 |

### 工作流程

1. **输入** → 用户输入偏差线索
2. **分析** → LLM 分析线索，提取关键信息
3. **识别** → 识别 5M1E 因素（人机料法环）
4. **匹配** → 匹配相关法规条款
5. **生成** → 模块化生成报告各部分
6. **审核** → 用户审核报告内容
7. **导出** → 导出 PDF 或发送审计

### 模版系统

模版分为 6 个独立模块：

1. **封面** - 报告标题、部门、签名
2. **背景** - 产品、批次、时间、地点、描述
3. **调查** - 根本原因、重复偏差、其他产品
4. **结论** - 根本原因、最可能原因
5. **风险评估** - 5 维影响评估
6. **CAPA** - 纠正措施、预防措施

每个模块可以单独编辑和生成，最后合并为完整报告。

## 常见问题

### Q: 报告生成失败怎么办？

A: 检查以下几点：
1. LLM 配置是否正确（设置页面）
2. API Key 是否有效
3. 网络连接是否正常
4. 尝试点击"重试"按钮

### Q: 如何提高报告质量？

A: 建议：
1. 提供详细的偏差描述
2. 上传相关文件（批记录、SOP 等）
3. 确保知识库中有相关法规
4. 使用高质量的 LLM Provider

### Q: 知识库搜索不准确？

A: 可能原因：
1. 文档未正确分块
2. 嵌入模型不匹配
3. 尝试使用语义搜索模式

### Q: 如何导出 PDF？

A: 步骤：
1. 生成报告后，在右侧文档面板点击"导出 PDF"
2. 选择保存位置
3. 等待 PDF 生成完成
